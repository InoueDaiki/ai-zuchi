# 検証: Web 検索の実装先

2026-11-01 時点。SearXNG は実際に動かした。Brave はキーがないので未実行で、下の記述は公式の文書による。

## 結論

**当面の既定は SearXNG にする。** 本人の手間なく今すぐ試せ、「BONX 差別化」の品質も十分だった。ただし検索エンジンの画面を機械で読むので、規約と安定性に弱みがある。常用して結果が不安定なら、Brave に切り替える(環境変数だけで切り替えられる)。Windows の機に Docker を入れたくない場合も Brave がよい。

`searcher_from_env` は `ZUCHI_SEARXNG_URL` を優先し、なければ `BRAVE_SEARCH_API_KEY` を見て、どちらもなければ検索しない。

## 比較

| 観点 | SearXNG(自前) | Brave Search API |
|---|---|---|
| 品質(「BONX 差別化」) | 49 件。公式サイト、代表の対談、日経クロストレンドなど使える結果が上位に並んだ。上位 5 件に無関係な「差別解消法」が混ざる回もあり、要約の前に絞り込みが要る | 未実行 |
| 速度 | 1.4〜1.7 秒(2 回の測定) | 未実行 |
| 費用 | 無料。動かす計算機の負荷のみ | 1,000 件 5 ドル。月 5 ドル分の無料クレジットで約 1,000 件 |
| 準備 | Docker と `settings.yml` の設定 | 登録とクレジットカード、API キー |
| Docker | 実質必須(公式の配布の中心)。常駐が 1 つ増える | 不要 |
| 規約 | SearXNG 自体は AGPL で、別のプログラムとして HTTP で使うだけなので、本体への影響はないと考える。ただし裏の検索エンジンの自動取得は、各社の規約に触れる可能性がある | 契約に基づく利用。下記の制限に注意 |
| 検索語の行き先 | 自分の IP から複数の検索エンジンへ | Brave の 1 社へ |
| 安定性 | 裏のエンジンに止められると結果が減る。今回は数回の試行で、長期の様子は未確認 | 有償の API。実測なし |

使用頻度の見積もりは、補足が 1 時間に 5〜15 件のうち検索が 3 分の 1、1 日 3 時間、月 22 日として月 110〜330 件。Brave の無料クレジットの範囲に収まる見込み。

## Brave の規約で注意する点

[Terms of Service](https://api-dashboard.search.brave.com/terms-of-service) より。

- 検索結果の保存、キャッシュ、データベース化は禁止。運用に必要な一時的な保存だけ例外。よって履歴には検索語だけを残す。補足の根拠として残す題名と URL が例外に入るかは、本人の判断が要る
- 検索結果を使った AI モデルの学習、評価、ベンチマーク、改善は禁止。**判定の評価データに Brave の結果を混ぜない**
- 帰属表示は任意
- クエリの保持期間は規約の本文にない。Privacy Notice の確認が要る

料金は[公式ページ](https://brave.com/search/api/)による。同じページに「月 20 ドル分まで無料」との記載もあり、プランの 5 ドルと食い違うので、低いほうで見積もった。

## SearXNG の動かし方

`settings.yml` で JSON を有効にする。これがないと 403 が返る([公式](https://docs.searxng.org/dev/search_api.html))。

```yaml
use_default_settings: true
server:
  secret_key: "乱数に置き換える"
  limiter: false
search:
  formats:
    - html
    - json
```

```bash
docker run -d --name searxng -p 127.0.0.1:8888:8080 \
  -v "$PWD/searxng:/etc/searxng" searxng/searxng:latest
export ZUCHI_SEARXNG_URL=http://127.0.0.1:8888
```

外から使われないよう `127.0.0.1` にだけ開ける。公開インスタンスは検索語を第三者に渡すので使わない。今回の版は 2026.10.30+ffa88e3ba。
